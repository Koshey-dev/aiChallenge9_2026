# aiChallenge — консольный чат с LLM по REST

Учебный проект курса по ИИ-агентам.

- `main.py` — чат с моделью: вопрос уходит в LLM по REST, ответ приходит потоком.
- `compare.py` — один и тот же вопрос на пяти уровнях контроля ответа: формат,
  длина, условие завершения.

Реализовано без SDK и фреймворков — голые HTTP-запросы через `requests`,
чтобы было видно, что именно уходит на сервер и что приходит обратно.

## Что умеет

- Диалог в консоли с сохранением истории: модель помнит предыдущие реплики
- Потоковый вывод ответа по мере генерации (Server-Sent Events)
- Работает с любым OpenAI-совместимым провайдером — меняются две константы

## Требования

- Python 3.10 или новее
- Ключ Google AI Studio: https://aistudio.google.com/apikey (бесплатный тариф, карта не нужна)

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env
```

Открыть `.env` и вписать ключ:

```
GEMINI_API_KEY=ваш_ключ
```

`.env` в `.gitignore` — ключ в репозиторий не попадёт.

## Запуск

```bash
py main.py
```

На Windows запускать через `py`, а не `python`: если в `PATH` есть другой
интерпретатор (например из MSYS2), он перехватит вызов и не найдёт
установленные пакеты.

Пример сессии:

```
╔═══════════════════════════════════════╗
║  ЧАТ С МОДЕЛЬЮ GEMINI-3.5-FLASH-LITE  ║
╚═══════════════════════════════════════╝
Запросы идут по REST API: POST https://generativelanguage.googleapis.com/...
Пустая строка или exit — выход.

> Столица Франции?
Столица Франции — Париж.

> А население?
Население Парижа — около 2,1 млн человек в черте города.

> exit
```

## Как устроено

Запрос уходит на OpenAI-совместимый эндпоинт Gemini:

```
POST https://generativelanguage.googleapis.com/v1beta/openai/chat/completions
Authorization: Bearer <ключ>
```

Тело — модель, вся история диалога и флаг потоковой отдачи:

```json
{
  "model": "gemini-3.5-flash-lite",
  "messages": [{"role": "user", "content": "..."}],
  "stream": true
}
```

Ключевые моменты реализации:

- **История.** Список `messages` живёт между итерациями цикла, ответ модели
  дописывается в него с ролью `assistant`. Без этого каждый вопрос уходил бы
  в пустоту, и «а население?» осталось бы без ответа.
- **Стриминг.** `stream=True` в `requests.post` не даёт библиотеке ждать
  ответ целиком, `flush=True` в `print` выталкивает символы в терминал сразу.
- **Кодировка SSE.** Строки режутся по байтам и декодируются в UTF-8 вручную.
  Штатный `iter_lines(decode_unicode=True)` здесь не годится: заголовок
  `text/event-stream` не несёт charset, requests откатывается на ISO-8859-1,
  и кириллица превращается в мусор, а JSON рвётся посреди символа.

## Сравнение уровней контроля ответа

```bash
py compare.py
```

Один и тот же вопрос уходит пятью запросами. Перед каждым печатаются параметры
запроса, после ответа — счётчики и `finish_reason`. Между уровнями пауза на Enter.

| Уровень | Чем ограничен | Что видно в ответе |
|---------|---------------|--------------------|
| L0 | ничем | простыня на 3000+ символов с заголовками и примерами |
| L1 | `max_tokens: 60` | обрыв на полуслове, `finish_reason: length` |
| L2 | инструкция в промпте | три пункта как просили, но `###КОНЕЦ` остался в тексте |
| L3 | промпт плюс `max_tokens` и `stop` | то же, но стоп-слово срезал сервер |
| L4 | `response_format: json_schema` | готовый JSON, парсится без чистки |

Главное в паре L2/L3. Ответы почти одинаковые, но инструкция в промпте — это
просьба: модель её выполнила и честно дописала стоп-слово в текст. Параметры
`max_tokens` и `stop` выполняет сервер, независимо от того, что решила модель, —
поэтому в L3 генерация оборвалась на совпадении и `###КОНЕЦ` в ответ не попал.

Ответы недетерминированы даже при `temperature: 0.2`: формулировки и счётчики
от прогона к прогону меняются.

## Смена провайдера

Эндпоинт OpenAI-совместимый, поэтому переезд — это правка `URL` и `MODEL`
в `main.py`, заголовок `Authorization: Bearer` везде одинаковый:

| Провайдер  | URL                                                |
|------------|----------------------------------------------------|
| Gemini     | `https://generativelanguage.googleapis.com/v1beta/openai/chat/completions` |
| Groq       | `https://api.groq.com/openai/v1/chat/completions`  |
| DeepSeek   | `https://api.deepseek.com/v1/chat/completions`     |
| OpenRouter | `https://openrouter.ai/api/v1/chat/completions`    |

## Ограничения

Это чат, а не агент:

- Нет инструментов. Модель не может прочитать файл, выполнить команду или
  узнать текущее время — только сгенерировать текст.
- История живёт в памяти процесса. Закрыл — забыл.
- Ответ отдаётся крупными порциями, а не посимвольно: так шлёт сервер.
